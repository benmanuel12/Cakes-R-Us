# Cakes 'R' Us Searchable and Editable Database

This is my work experience project from Dow Jones Web Development Team.
It was intended to be a website for uploading, storing and modifying cake orders, but due to time constraints it ended up with a mix of mostly unrelated features

## Built with
Node.js, JavaScript

## nodemodules Dependencies:
- express
- fs
- path
- body-parser
- multer
- jsonfile

## Features
- Lists cakes entered using the form
- Can add cakes by choosing the name, flavours, topping and shape
- Has a non-functional page for uploading files
- Homepage that links to the other pages
- Page that displays some images in a table

## Running it
1) Copy/Download repository to your GitHub folder.
2) Open Command Prompt and navigate to the 'Cakes-R-Us' folder.
3) Type 'node index.js' and press enter.
4) Navigate to localhost:8083 in a web browser
